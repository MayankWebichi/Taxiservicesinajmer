## 9. Booking System

### Booking Form
- **Trip Tabs:** One Way | Round Trip | Airport
- **Fields:** Pickup City, Drop City, Pickup Date, Pickup Time, Vehicle (dropdown + image picker)
- **Round Trip Extra Fields:** Return Date, Return Time
- **CAPTCHA:** Simple math CAPTCHA (e.g., 8 + 4 = ?)
- **Backend API:** POST to `/api/booking.php`
- **Guest booking:** Allowed (name + phone + email)
- **Account booking:** Login/Register to save bookings

### Booking Flow Steps
1. Select trip type
2. Enter pickup/drop cities, date, time
3. Select vehicle (see image + price)
4. Enter passenger details (or login)
5. Solve math CAPTCHA
6. Submit → booking request sent
